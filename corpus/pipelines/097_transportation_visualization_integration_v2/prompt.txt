# Independent operational summaries converging into a report

1. Objective

Build a four-task pure fan-in graph. Three independent roots validate and compute route, vehicle, and weather summaries. Route and weather include passenger-km and on-time=(delay<=5); vehicle includes passenger, fare, and delay measures. A final task consumes all three artifacts and reconciles trip totals and group counts.

2. Available input files

- inputs/data.csv
  Columns present: trip_id, route, vehicle_type, departure_hour, distance_km, passengers, fare_amount, delay_minutes, day_of_week, is_holiday, weather_condition

These are available source columns, not a requirement to use every column. Follow the task-specific column-selection and validation rules below. Input paths are relative to the supplied generation workspace.

3. Required processing behavior

Apply all processing requirements in the objective above. Retain its specified transformations, parameters, validation policies and ordering.

4. Dependency and topology requirements

Preserve the logical ordering, data dependencies, independent branches and joins specified in the objective and processing requirements. Independent branches must not acquire dependencies on one another; joins must consume the required current-run upstream artifacts. Do not replace a required branched pipeline with a sequential chain or add a join between independent components. Logical task counts stated in the requirements describe required operations; any permitted alternative Dagster decomposition must preserve their behavior, topology and observable checkpoints.

5. Mandatory output artifacts

- `route_operations.csv`
- `vehicle_operations.csv`
- `weather_operations.csv`
- `operations_report.json`

6. Execution and numerical requirements

Execution contract: generate executable local Dagster code without networks, prior outputs, fixed answers, or human intervention. Preserve the declared artifact-backed topology and write beneath the run output directory. Numeric comparisons use atol=1e-6 and rtol=1e-6; JSON must contain only finite values. Reject missing required columns, blank or duplicate identifiers, and non-finite required numeric values.

7. Deliverable
