# Three sports summaries converging into a report

Build pure fan-in. Independent roots produce team production, position play/shooting, and four age-band summaries. Final report reconciles player totals and publishes team/position/band counts and highest-scoring team. Branches do not depend on one another.

Execution contract: generate executable local Dagster code without networks, prior outputs, fixed answers, or human intervention. Preserve the declared artifact-backed topology. Write beneath the run output directory. Numeric comparisons use atol=1e-6 and rtol=1e-6; JSON must be finite. Invalid identifiers, missing columns, or non-finite required values fail clearly.

Mandatory output files:
- `team_summary.csv`
- `position_summary.csv`
- `age_summary.csv`
- `sports_report.json`
